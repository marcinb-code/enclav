Secure cutting. Confidential computing.

Packly.cc is an instant, browser-based GPU-accelerated hybrid platform for 2D nesting and CAM automation designed to optimize material cutting for both craft workshops and industrial enterprises, which redefines industrial security by protecting your proprietary designs through zero-knowledge data privacy and fully local, secure compute environments.

YOUR CAD STAYS ON DEVICE · LOCAL WASM PARSER · ANONYMIZED GEOMETRY · ISOLATED GPU · ONE-TIME COMPUTE · DESTROYED

Secure cutting. Confidential computing.

Your CAD file never leaves your device. A local WASM parser extracts the required geometry, which is then anonymized. Only the necessary geometric data is sent to an isolated GPU environment for one-time computation. After nesting/CAM is complete, the environment is destroyed and the result is returned to you.

Your CAD file stays. Only the required geometry moves.

The original CAD file remains on the user's device. A local WASM parser extracts the required geometry, which is then anonymized. Only the necessary geometric data is sent to the isolated GPU environment for one-time computation. After the processing lifecycle completes, the compute environment is destroyed and the result is returned to the user.

  1. 01 — Import

    Import supported CAD geometry.

  2. 02 — Local parsing

    A local WASM parser extracts the geometric information needed for the task.

  3. 03 — Anonymization

    The extracted geometry is processed to remove identifying or unnecessary information according to the implemented anonymization rules.

  4. 04 — Isolated compute

    Only the required geometric data is sent to the isolated GPU environment for one-time computation.

  5. 05 — Result delivery

    The computed result is returned to the originating workflow.

  6. 06 — Environment destruction

    The one-time compute environment is destroyed after the processing lifecycle completes.

Industrial designs deserve better protection.

CAD files can reveal more than their geometry.

They may contain information about:

  • Product design.
  • Part dimensions.
  • Manufacturing methods.
  • Customer projects.
  • Proprietary geometry.
  • Production requirements.

Sending original design files to external processing services may expose information unnecessarily.

Packly is built around the idea of separating original CAD files from the minimum geometry data required for computation.

Make better use of every sheet.

Nesting is the process of arranging individual parts on a material sheet to reduce waste and improve material utilization.

Packly's initial product direction focuses on:

  • 2D flat metal parts.
  • Sheet dimensions.
  • Part quantities.
  • Geometry constraints.
  • Allowed rotations.
  • Part spacing.
  • Material utilization.
  • Waste analysis.

The initial product scope is deliberately focused on metal sheet cutting.

Use compute where it makes a difference.

GPU acceleration can help execute suitable computational workloads efficiently.

Packly's technical direction includes GPU-based compute for supported processing tasks.

Performance should be evaluated through:

  • Processing time.
  • Queue time.
  • GPU utilization.
  • Memory usage.
  • Input complexity.
  • Nesting quality.
  • Result consistency.

Separate geometry optimization from machine-specific production.

A nesting result and a production-ready machine program are different outputs.

Machine-neutral nesting

  • Geometry.
  • Part placement.
  • Transformations.
  • Sheet boundaries.
  • Spacing constraints.
  • Collision validation.
  • Material utilization.

Machine-specific CAM

  • Machine profile.
  • Process configuration.
  • Material and thickness.
  • Kerf compensation.
  • Tooling.
  • Lead-in and lead-out.
  • Feed and speed.
  • Cutting sequence.
  • Postprocessor.
  • Controller-specific output.

Production G-code requires a complete and validated Machine Profile.

Your geometry. Your control.

Packly's privacy approach is based on keeping the original CAD file on the user's device and limiting the information transferred for computation to the geometry required for the task.

The page makes the following distinctions:

  • Original CAD file.
  • Locally extracted geometry.
  • Anonymized geometry.
  • Isolated compute environment.
  • Returned result.
  • Compute environment destruction.

Built around a focused industrial workflow.

Packly's development direction prioritizes:

  • 2D Metal Nesting — A focused initial application for flat-sheet metal cutting.
  • Nesting Quality — Validation of geometry correctness, placement and material utilization.
  • Compute Optimization — Evaluation of CPU and GPU execution according to actual workload performance.
  • CAM Expansion — Further development of machine-specific workflows after validated Machine Profile support.
  • Privacy Architecture — Continued verification of data minimization, processing lifecycle and privacy controls.
